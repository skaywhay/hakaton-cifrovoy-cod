## 1. О проекте и его назначение

Веб-ресурс **«Цифровой код: Навигатор IT-профессий»** разработан в рамках кейса «Профессии в IT: найди своё будущее» V Регионального хакатона «Цифровой код» (2026). Проект представляет собой специализированную цифровую платформу ранней профориентации для учащихся старших классов (8–11 классы).

Основная цель ресурса — трансформировать абстрактное представление школьников об информационных технологиях в структурированное понимание реальных профессиональных траекторий, производственных задач, стека применяемых инструментов и требований рынка труда.

### Задачи платформы:
- Систематизация знаний о ведущих направлениях в индустрии разработки ПО, анализа данных, системного администрирования, тестирования и дизайна.
- Диагностика предрасположенности и интересов учащегося посредством комплексного интерактивного тестирования из 6 практических сценариев.
- Сопоставление выявленных предпочтений с 10 ключевыми IT-специальностями через динамический алгоритм взвешенного скоринга.
- Формирование пошагового образовательного маршрута: профильные олимпиады (ВсОШ, НТО), рекомендуемые учебные платформы, книги и бесплатные курсы.
- Интерактивное погружение через мини-симуляторы рабочих задач («тест-драйв за 30 секунд») и генерацию цифрового паспорта IT-специалиста (Cyber-ID DevCard).

## 2. Архитектура и функциональная структура веб-ресурса

Приложение спроектировано по архитектуре Single Page Application (SPA) с клиентской маршрутизацией на базе History API и хэш-навигации (`#screenHero`, `#screenQuiz`, `#screenResult`, `#screenCatalog`, `#screenCompare`).

### Ключевые экраны приложения:

1. **Стартовый экран (Hero):**
   - Презентация образовательной миссии платформы и регламента хакатона.
   - Быстрый доступ к опроснику, каталогу профессий и экрану сравнения.
   - Интерактивная витрина специальности с циклической сменой направлений без перезагрузки страницы.
   - Блок отображения предыдущего результата диагностики (извлечение из `localStorage`).
   - Ключевые метрики платформы (10 специализаций, 6 сценариев анализа, верифицированные источники).

2. **Экран интерактивного опроса (6 шагов):**
   - **Шаг 1. Архитектурный фокус:** карточки с иконками ключевых областей (клиентский интерфейс, серверная логика, данные, инфраструктура).
   - **Шаг 2. Разбор рабочего инцидента:** практический кейс (падение конверсии на проде) с вариантами решения.
   - **Шаг 3. Баланс деятельности:** плавный кастомный ползунок распределения времени между кодом, аналитикой, визуалом и коммуникацией.
   - **Шаг 4. Ключевая ценность продукта:** выбор главного приоритета (UX, отказоустойчивость, безопасность, масштабируемость).
   - **Шаг 5. Формат решения задач:** самостоятельное исследование, командный парный кодинг, регламентированный процесс.
   - **Шаг 6. Предпочитаемый стек технологий:** скриптовые языки, компилируемые системы, декларативные конфигурации.
   - Линейный прогресс-бар, счетчик шагов и методические подсказки к каждому этапу.

3. **Экран результатов диагностики:**
   - Расчет и визуализация процентного индекса совпадения (Match Score) по нормализованной матрице весов.
   - Развернутая карточка рекомендованной специальности: описание роли, задачи рабочего дня, ключевые компетенции (Hard & Soft Skills).
   - Индивидуальный образовательный маршрут из 4 последовательных этапов (база, пет-проект, олимпиады, стажировка).
   - Сетка рекомендованных учебных платформ и профильных олимпиадных треков перечня РСОШ и Минпросвещения РФ.
   - Экспорт результата: возможность поделиться в социальных сетях и мессенджерах, копирование персональной ссылки, генерация цифрового паспорта.

4. **Каталог IT-профессий (10 направлений):**
   - Интерактивный поиск по ключевым словам, названиям технологий и навыкам.
   - Категориальные фильтры: Разработка, Тестирование, Инфраструктура, Безопасность, Данные и AI, Дизайн.
   - Модульные карточки профессий: вилка зарплат (Junior / Middle / Senior), требования к порогу входа, стек технологий.
   - Система закладок («Избранное») с сохранением в локальном хранилище браузера.
   - Встроенные кнопки запуска интерактивных симуляторов задач.

5. **Экран сопоставления ролей (Side-by-Side Comparator):**
   - Сравнительный анализ двух любых выбранных профессий из базы данных.
   - Сводная матрица параметров: ключевой стек, уровень математической подготовки, порог входа, базовый инструментарий, измеримый результат работы, классификатор направлений подготовки в вузах РФ (ОКСО).

### Модальные функциональные модули:
- **Социальный рейтинг востребованности (Leaderboard Modal):** интерактивное голосование за профессии с защитой от накрутки и агрегацией в `localStorage`.
- **Сведения об использовании ИИ (AI Documentation Modal):** официальная декларация применения инструментов искусственного интеллекта в соответствии с разделом 4 регламента.
- **Интерактивные тест-драйвы (Simulators Modal):** встроенные мини-игры для практической пробы задач специальности.
- **Генератор цифрового паспорта (Cyber-ID Modal):** формирование графического сертификата на HTML5 Canvas с 3D-эффектом перспективы при движении курсора.

## 4. Геймификация и интерактивные симуляторы («Цифровой код 2.0»)

В проект интегрирован комплекс прикладных игровых механик, реализованный по принципу неразрушающего расширения (Non-destructive enhancement):

1. **Система опыта (XP Engine) и глобальный HUD:**
   - Плавающий виджет профиля в шапке сайта: отображение текущего ранга (Junior -> Middle -> Senior -> Lead), числового опыта и прогресс-бара до следующего уровня.
   - Начисление опыта за целевые действия: прохождение теста (+200 XP), решение симулятора (+150 XP), сравнение направлений (+50 XP), добавление в избранное (+25 XP).
   - Всплывающие уведомления (Toast Notifications) в стиле темного интерфейса разработчика с анимацией скольжения.
   - Персистентность: сохранение достижений и опыта в `window.localStorage`.

2. **Практические симуляторы задач («Тест-драйв за 30 секунд»):**
   - **Frontend (CSS Rescue):** интерактивная песочница Flexbox (`justify-content` и `align-items`) с центрированием элемента в эмуляторе экрана.
   - **QA-инженер (Bug Hunter):** интерактивная форма входа с поиском 3 скрытых дефектов (отрицательный возраст, побег кнопки, инвертированный ввод).
   - **Кибербезопасность (Firewall Log Patrol):** консоль мониторинга логов веб-сервера с таймером и поиском SQL-инъекции.
   - **Backend (SQL Query Builder):** сборка корректного SQL-запроса фильтрации пользователей по токенам.
   - **GameDev (Physics Jump):** симуляция физики прыжка на Canvas с подбором силы гравитации и импульса.
   - **UI/UX (Contrast Master):** подбор цветовой пары текста и фона с проверкой коэффициента контрастности по WCAG AA.
   - **DevOps (Pipeline Runner):** запуск этапов сборки, тестирования и деплоя контейнеров.
   - **AI/ML (Loss Function Optimizer):** интерактивный график оптимизации функции потерь нейросети.

3. **Генератор паспорта IT-специалиста (Cyber-ID DevCard):**
   - Процедурный рендеринг персональной карточки на HTML5 Canvas (600x850 px).
   - Вывод имени учащегося, определенной роли, числовых характеристик (Логика, Креативность, Детализация, Обучаемость), уникального серийного номера HASH-#XXXX и штрих-кода.
   - Интерактивный 3D-наклон карточки при движении курсора (CSS Perspective).
   - Скачивание карточки в формате PNG в один клик.

4. **Процедурный синтезатор звуков (Web Audio API):**
   - Синтез звуковых эффектов (клики, успешные действия, начисление XP) через генераторы `OscillatorNode` без загрузки внешних аудиофайлов.
   - Кнопка отключения звукового сопровождения в верхнем баре с сохранением состояния.

## 5. Дизайн-система и стандарты верстки

В результате визуального рефакторинга интерфейс очищен от маркеров любительской верстки («вайбкодинга»): устранены неоново-малиновые градиенты, чрезмерные скругления (32px), размытые тени и плавающие отступы. Интерфейс приведен к стандарту современных российских продуктовых сервисов (Яндекс Практикум, Т-Банк, Stepik).

### Принципы дизайн-системы:
- **Цветовая палитра:**
  - Основной технологичный цвет: Deep Tech Blue (`#1D4ED8`, `#1E40AF`, `#172554`).
  - Фон рабочей области: Slate Canvas (`#F8FAFC`).
  - Поверхности карточек и модальных окон: Pure White (`#FFFFFF`).
  - Текстовая шкала: Dark Slate (`#0F172A`, контрастность 14.5:1 к белому фону) для заголовков; Slate Secondary (`#475569`, контрастность 7.0:1) для пояснительного текста. Соответствие стандарту WCAG AAA / AA.
  - Функциональный акцент готовности и прогресса: Emerald (`#059669`, подложка `#ECFDF5`).
- **Модульная 8-пиксельная сетка (Strict 8pt Grid):**
  - Шапка сайта: высота ровно 64px (8 * 8).
  - Кнопки: 40px (стандартная), 48px (акцентный CTA), 32px (компактная в шапке).
  - Внутренние отступы карточек и контейнеров: 16px, 24px, 32px.
  - Модульные гэпы сеток: 12px, 16px, 24px, 32px.
- **Шкала скруглений (Radii Scale):**
  - Микро-теги и бейджи: 4px (`--radius-xs`).
  - Кнопки, инпуты, селекты, чипы: 6px (`--radius-s`).
  - Интерактивные варианты опроса: 8px (`--radius-m`).
  - Основные карточки, витрина Hero, модальные окна: 12px (`--radius-l`).
  - Ликвидированы 32-пиксельные пузыри и нефункциональные круглые кнопки-пилюли.
- **Тональные возвышения (Elevations):**
  - Естественные нейтральные тени на базе спектра Slate (`rgba(15, 23, 42, 0.05..0.08)`) без цветных ореолов.
- **Типографическая шкала:**
  - Базовый шрифт: Inter (`font-weight: 400, 500, 600, 700`).
  - Технический и числовой шрифт: JetBrains Mono для отображения метрик, опыта, шкал, кода и серийных номеров.
  - Жестко зафиксированные пропорции line-height и отрицательного трекинга (letter-spacing) для заголовков.
- **Доступность (Accessibility & a11y):**
  - Контрастные состояния `:focus-visible` с двухпиксельным контуром и смещением `outline-offset: 2px`.
  - Поддержка медиавыражения `@media (prefers-reduced-motion: reduce)` для пользователей с чувствительностью к анимациям.
  - Полноценная адаптивность (Mobile-First): корректный перенос на экранах смартфонов (до 640px), планшетов (641–992px) и десктопов без появления горизонтальной полосы прокрутки.

## 6. Технологический стек проекта

Проект выполнен на чистом стеке веб-технологий без использования тяжелых сторонних фреймворков и компиляторов:

- **HTML5:** семантическая верстка (`header`, `main`, `section`, `article`, `nav`, `aside`, `dialog`, `fieldset`, `legend`), поддержка WAI-ARIA атрибутов.
- **CSS3:** модульная компоновка на CSS Grid и Flexbox, кастомные свойства (CSS Variables / Design Tokens), логические свойства (`margin-inline`, `padding-inline`), CSS transitions на кривых Безье `cubic-bezier(0.16, 1, 0.3, 1)`.
- **Vanilla JavaScript (ES6+):** модульная логика, History API, LocalStorage API, события клавиатуры и указателя.
- **HTML5 Canvas API:** процедурная генерация графических сертификатов высокого разрешения (600x850 px).
- **Web Audio API:** синтез звуковых волн в реальном времени (AudioContext, OscillatorNode, GainNode).
- **Векторная графика:** нативные inline SVG-иконки без внешних шрифтовых наборов (FontAwesome и др.).
- **Оффлайн-автономность:** проект запускается локально без сервера и доступа к сети по протоколу `file:///`.

## 7. Инструкция по установке и локальному запуску

Проект готов к моментальному запуску, не требует установки пакетов через npm, pip или сборки через Webpack/Vite.

### Вариант 1. Прямой запуск файла (рекомендуемый для жюри)
1. Скачайте репозиторий или распакуйте архив проекта в локальную папку.
2. Откройте файл `index.html` двойным кликом в любом современном веб-браузере (Яндекс Браузер, Google Chrome, Mozilla Firefox, Microsoft Edge, Safari).

### Вариант 2. Запуск через встроенный веб-сервер Python
Выполните команду в корневой папке проекта:
```bash
python -m http.server 8080
```
После запуска перейдите в браузере по адресу:
```
http://localhost:8080
```

### Вариант 3. Запуск через Node.js (npx serve)
```bash
npx serve .
```

В соответствии с **Разделом 7 регламента хакатона**, итоговый комплект материалов включает:

1. `index.html` — единая исполняемая точка входа веб-приложения (семантическая разметка HTML5, структура SPA-экранов, модальные окна).
2. `gamification.css` — стили модуля геймификации (HUD, интерактивные симуляторы, стили карточки Cyber-ID, тосты опыта).
3. `gamification.js` — JavaScript-движок геймификации (система уровней и XP, 8 симуляторов профессий, генератор Cyber-ID Canvas, Web Audio API).
4. `professions.json` — структурированная база данных 10 профессий со стеком, обязанностями и образовательными маршрутами.
5. `README.md` — исчерпывающее техническое руководство, архитектурное описание, спецификация дизайн-системы и источников.
