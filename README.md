## 📌 О проекте

**«Цифровой код: Навигатор IT-профессий»** — это интерактивный веб-продукт (SPA), созданный для осознанного профессионального самоопределения школьников и подростков в динамичном мире современных информационных технологий.

Продукт помогает учащимся:
1. Разобраться в многообразии IT-специализаций и понять, чем занимаются специалисты на реальной практике.
2. Пройти интерактивную диагностику с разноформатными вопросами и получить персональную рекомендацию с процентом совпадения.
3. Узнать ключевые hard & soft skills, применяемые инструменты, языки программирования и рабочие задачи.
4. Провести глубокое сравнительное сопоставление любых двух профессий (Side-by-Side).
5. Построить образовательную траекторию с переходом на проверенные государственные платформы, олимпиады (ВсОШ, НТО) и профильные вузы.

## 🌟 Ключевой функционал

### 1. Интерактивная профориентационная диагностика (6 типов вопросов)
- **Вопрос 1 (Сетка визуальных карточек):** определение базового вектора интереса (интерфейсы, алгоритмы, безопасность, аналитика).
- **Вопрос 2 (Инженерный кейс-инцидент):** поведение при критическом сбое перед релизом продукта.
- **Вопрос 3 (Слайдер баланса мышления):** выбор баланса между «Творчеством/UX» и «Строгой логикой/Архитектурой».
- **Вопрос 4 (Ценностный ориентир):** определение главной мотивации в будущей работе.
- **Вопрос 5 (Роль в команде):** проектировщик, создатель движков, исследователь данных или тестировщик-контролёр.
- **Вопрос 6 (Технологический стек):** предпочтительные среды и инструменты разработки.

### 2. Экран персонального результата
- Анимированный цифровой счётчик совместимости (до 94–96%).
- Детальный профиль профессии: описание миссии, реальные задачи, стек технологий, мягкие навыки (Soft Skills) и ключевые этапы старта в профессии.

### 3. Каталог 10 востребованных IT-профессий
Каталог с живым полнотекстовым поиском и фильтрацией по направлениям:
1. **Frontend-разработчик** (HTML5, CSS3, JavaScript, React, TypeScript, Vite)
2. **Backend-разработчик** (Python, Go, PostgreSQL, Docker, REST/gRPC, Linux)
3. **Мобильный разработчик** (Kotlin, Swift, Flutter, Android Studio, Firebase)
4. **GameDev-разработчик** (Unity, C#, Unreal Engine, C++, 3D-математика)
5. **UI/UX-дизайнер** (Figma, UX Research, Design Systems, Прототипирование)
6. **QA-инженер / Тестировщик** (PyTest, Selenium, Postman, DevTools, CI/CD)
7. **DevOps / SRE-инженер** (Kubernetes, Docker, CI/CD, Terraform, Bash)
8. **Специалист по кибербезопасности** (Network Security, OWASP, Криптография, SIEM)
9. **Data Scientist / Аналитик данных** (Python, Pandas, SQL, Tableau, Математическая статистика)
10. **AI / ML-инженер** (PyTorch, TensorFlow, Hugging Face, LLM, Computer Vision)

### 4. Инструмент сравнения профессий (Side-by-Side Comparator)
Интерактивный экран, позволяющий сопоставить любые две специальности по 6 параметрам:
- Основной фокус и миссия;
- Уровень порога входа для школьника;
- Базовый инструментарий;
- Приоритетные личные качества;
- Типовой результат рабочего дня;
- Профильные направления подготовки в вузах.

### 5. Социальный лидерборд и система «Избранное»
- Голосование за наиболее интересные направления с сохранением голосов в `localStorage`.
- Добавление карточек профессий в персональный список «Избранное» с мгновенным доступом.

## 🛠 Технологический стек и архитектура

Проект выполнен в соответствии с критериями номинации **«Web-разработка»**:
- **HTML5**: Семантическая доступная разметка (WAI-ARIA, семантические теги `header`, `main`, `section`, `article`, `dialog`).
- **CSS3 (Modern UI)**:
  - Палитра: Базовый seed-цвет `#B888B1` (Muted Mauve), светлый чистый фон `#FAF7F9`, акцентный primary `#76336F`, контейнер `#FFD7F3`, деликатные границы `#D1C3CC`.
  - Tonal Elevation: отсутствие тяжёлых черных теней, мягкое распределение фонов и слоёв.
  - Адаптивная вёрстка (CSS Grid, Flexbox, Mobile-First медиазапросы).
- **Чистый JavaScript (ES6+)**:
  - Архитектура SPA (Single Page Application) без перезагрузки страниц и сторонних фреймворков.
  - Матричный скоринг ответов теста.
  - Локальное хранилище данных (`window.localStorage`) для сохранения результатов, голосов и избранного.
- **Векторная графика**: Встроенные масштабируемые SVG-иконки без использования эмодзи и внешних шрифтовых иконок.
- **Автономность**: Проект не требует интернета для функциональной работы (кроме подгрузки шрифта Google Fonts, для которого предусмотрен системный fallback-стек).

## 🚀 Инструкция по запуску

Проект не требует установки сложных зависимостей или сборщиков (Webpack/Vite). Он готов к немедленному запуску.

### Способ 1: Прямой запуск в браузере (быстрый старт)
1. Откройте папку проекта.
2. Дважды кликните по файлу `index.html` или перетащите его в любой современный браузер (Google Chrome, Яндекс Браузер, Firefox, Safari, Microsoft Edge).

### Способ 2: Запуск через локальный веб-сервер

#### Python (рекомендуется):
```bash
# Перейдите в папку с проектом
cd "e:/мои проекты/цифровой-код"

# Запустите встроенный HTTP-сервер
python -m http.server 8080
```
После запуска откройте в браузере адрес: **[http://localhost:8080](http://localhost:8080)**

#### Node.js / npx:
```bash
npx serve "e:/мои проекты/цифровой-код"
```

## 🤖 Документация использования искусственного интеллекта

В строгом соответствии с **Разделом 4 Положения кейса** («Использовать ИИ при разработке продукта... но команда отвечает за итоговую работу и проверяет результаты генерации»):

1. **Где и как применялся ИИ:**
   - **Генерация и структурирование описаний:** ИИ привлекался для составления первичных драфтов матриц компетенций, формулирования практических кейсов и сопоставления связок hard/soft skills.
   - **Векторная графика:** ИИ помог оптимизировать геометрию базовых SVG-пиктограмм для соблюдения строгой минималистичной стилистики.
   - **Ревизия кода:** Проведение статического анализа, оптимизация математики расчёта совместимости и проверка краевых случаев в алгоритме поиска.

2. **Верификация и доработка человеком:**
   - Исключены любые шаблонные иллюстрации нейросетей и мультяшные персонажи в пользу строгой системной графики.
   - Все ссылки, названия стандартов и олимпиадных треков сопоставлены с официальными российскими образовательными перечнями.
   - Проверена кроссбраузерность, логика переключения экранов, доступность клавиатурной навигации и контрастность палитры.
