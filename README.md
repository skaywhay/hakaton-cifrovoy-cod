## 1. О проекте и его назначение

Веб-ресурс **«Цифровой код: Навигатор IT-профессий»** разработан в рамках кейса «Профессии в IT: найди своё будущее» V Регионального хакатона «Цифровой код» (2026). Проект представляет собой специализированную цифровую платформу ранней профориентации для учащихся старших классов (8–11 классы).

Основная цель ресурса — трансформировать абстрактное представление школьников об информационных технологиях в структурированное понимание реальных профессиональных траекторий, производственных задач, стека применяемых инструментов и требований рынка труда.

### Задачи платформы:
- Систематизация знаний о ведущих направлениях в индустрии разработки ПО, анализа данных, системного администрирования, тестирования и дизайна.
- Диагностика предрасположенности и интересов учащегося посредством комплексного интерактивного тестирования.
- Сопоставление выявленных предпочтений с математической матрицей компетенций и расчет индекса совпадения (Match Index).
- Предоставление наглядного сравнительного анализа между смежными IT-специальностями.
- Формирование верифицированного образовательного маршрута со ссылками на государственные образовательные инициативы, олимпиадное движение (ВсОШ, НТО) и профильные направления подготовки высшего образования.

## 2. Архитектурное обоснование структуры ресурса (Старшая категория)

Согласно регламенту кейса для старшей возрастной группы (8–11 классы), веб-ресурс должен обладать целостной структурой и содержать **не менее трёх связанных содержательных разделов**.

Для обеспечения максимальной производительности, мгновенного отклика интерфейса и бесшовного пользовательского опыта проект спроектирован по архитектурной модели **Single Page Application (SPA)** на нативном технологическом стеке без внешних фреймворков. В структуре приложения выделено **5 полноэкранных изолированных разделов** и **2 вспомогательных модальных модуля**:

### Содержательные разделы приложения:
1. **Главный экран (Hero Section)**  
   Презентационный экран, раскрывающий цели платформы, ключевые метрики индустрии (10 ролей, 6 этапов диагностики, навигатор источников), а также интерактивную витрину-слайдер для предварительного ознакомления с профилями IT-специальностей.
2. **Профориентационная интерактивная диагностика (Quiz Section)**  
   Многофакторный опросный модуль, включающий 6 разнотипных механик взаимодействия: выбор визуальных направлений, моделирование инженерного инцидента, калибровка баланса творческого и системного мышления с помощью ползунка, определение ценностных приоритетов, выбор командной роли и предпочтительного технологического стека.
3. **Экран персонального результата (Result Section)**  
   Детальный паспорт рекомендуемой профессии: анимированный индикатор совпадения, описание отраслевой роли, 4 типовые производственные задачи, перечень жестких навыков (Hard Skills), перечень гибких навыков (Soft Skills) и пошаговый алгоритм обучения с 1-го по 4-й этап.
4. **Каталог IT-направлений (Catalog Section)**  
   Полнофункциональный реестр 10 востребованных профессий с живым клиентским поиском по ключевым словам и стеку, категоризацией по направлениям, быстрым переходом к полному профилю профессии («Подробнее») и системой сохранения карточек в локальное «Избранное».
5. **Экран сравнительного анализа профессий (Side-by-Side Compare Section)**  
   Аналитический компаратор, позволяющий выбрать любые две специальности из базы данных и получить сравнительную матрицу по 6 фундаментальным критериям: целевой фокус, порог входа для школьника, базовые рабочие инструменты, профильные личные качества, измеримый результат рабочего дня, классификатор направлений подготовки в вузах РФ.

### Модальные функциональные модули:
- **Модуль социального рейтинга (Leaderboard Modal):** интерактивное голосование за профессии с сохранением пользовательского голоса и агрегацией в `window.localStorage`.
- **Модуль информации об использовании ИИ (AI Documentation Modal):** специализированный диалог, раскрывающий границы и методы привлечения инструментов искусственного интеллекта при проектировании ресурса.

## 4. Технологический стек и инженерные решения

Проект реализован в строгом соответствии с требованиями к номинации «Web-разработка»:

- **HTML5:**
  - Полная семантическая разметка документа (`header`, `main`, `section`, `article`, `dialog`).
  - Обеспечение доступности (WAI-ARIA атрибуты, корректная иерархия заголовков `h1`–`h4`, поддержка навигации с клавиатуры).
- **CSS3:**
  - Дизайн-система построена на принципах тональной элевации (Tonal Elevation) без использования тяжелых контрастных теней.
  - Палитра: доминантный seed-цвет `#B888B1` (Muted Mauve), светлый фон рабочей области `#FAF7F9`, акцентный оттенок `#76336F`, контейнер `#FFD7F3`, деликатные разделители `#D1C3CC`.
  - Адаптивная компоновка: использование модулей CSS Grid и Flexbox с набором медиавыражений (Mobile-First) для корректного отображения на мобильных телефонах, планшетах и широкоформатных мониторах.
- **JavaScript (ECMAScript 2020+):**
  - Чистый JavaScript без привлечения сторонних библиотек и рантайм-зависимостей (Vanilla JS).
  - Алгоритм скоринга: взвешенный расчет соответствия ответов векторам компетенций с динамической нормализацией результата.
  - Изолированное хранилище состояния: применение API `window.localStorage` для персистентного хранения закладок, истории последнего совпадения и распределения голосов в рейтинге.
- **Векторная графика:**
  - Все иконки и графические маркеры выполнены в виде масштабируемых векторных контуров SVG (Scalable Vector Graphics), встроенных непосредственно в разметку, что исключает внешние сетевые запросы к шрифтовым серверам.
- **Автономность решения:**
  - Приложение полностью функционально в автономном режиме при локальном открытии файла без подключения к сети Интернет.

## 5. Инструкция по установке и локальному запуску

Проект не требует компиляции, установки пакетов через менеджеры зависимостей или выполнения сборочных скриптов.

### Вариант 1. Прямой запуск в веб-браузере
1. Загрузите или распакуйте файлы проекта в любую локальную папку.
2. Откройте файл `index.html` в любом современном веб-браузере (Яндекс Браузер, Google Chrome, Mozilla Firefox, Microsoft Edge, Safari).

### Вариант 2. Запуск через встроенный веб-сервер Python
Выполните команду в корневой папке проекта:
```bash
python -m http.server 8080
```
После запуска перейдите в браузере по адресу:
```
http://localhost:8080
```

### Вариант 3. Запуск через Node.js (npx)
Выполните команду в корневой папке проекта:
```bash
npx serve .
```

## 6. Декларация использования инструментов искусственного интеллекта

В соответствии с **Разделом 4 Положения хакатона** («Использовать ИИ при разработке продукта... но команда отвечает за итоговую работу и проверяет результаты генерации»), авторский коллектив фиксирует следующие границы использования нейросетевых инструментов:

### 1. Направления применения ИИ:
- **Вспомогательная генерация черновых описаний:** алгоритмы генерации текста привлекались на начальном этапе проектирования для формирования первичных списков производственных обязанностей и черновых описаний профессий.
- **Оптимизация геометрических координат SVG:** векторные контуры части пиктограмм были оптимизированы с помощью алгоритмов минимизации точек сплайнов.

### 2. Полностью самостоятельная разработка команды:
- Программная логика приложения, архитектура SPA, механизм маршрутизации экранов и скоринг ответов написаны авторами проекта вручную.
- Дизайн-система, цветовая гармония (Muted Mauve), верстка и адаптивные сетки спроектированы и отлажены авторами без шаблонных генераторов.
- Все текстовые материалы, перечни навыков, связки технологий и олимпиадные треки прошли полную ручную вычитку, фактчекинг и адаптацию под требования нормативных документов РФ.
